# Prateleira

Projeto desenvolvido com Vue e TypeScript no Front-end e Rust no Back-end, sendo uma rede social voltada para leitura

## Para o correto funcionamento da aplicação é necessário realizar as seguintes alterações:
Download do arquivo GeoLite2-City.mmdb disponível em https://github.com/P3TERX/GeoLite.mmdb

## Para executar o back-end, executes os comandos:
cd back-end

cargo run

## Para executar o front-end, executes os comandos:
cd front-end

npm install

npm start
